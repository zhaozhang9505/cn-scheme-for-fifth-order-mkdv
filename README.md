# Numerical study of anomalous interactions in the fifth-order mKdV equation

This repository contains the MATLAB source code used for the numerical experiments and validation tests in Sections 3, 4, and 5 of the paper.

## Tables 1--4

The following files reproduce the numerical tests reported in Tables 1--4 of the revised manuscript:

- `reviewer_benchmarks.m`  
  Common solver and data-output routine used by the table programs. The finite-window sensitivity test for Table 4 is also contained in this file.

- `Table1_temporal_dx_0p00625.m`  
  Temporal refinement test for Table 1 at fixed `dx = 0.00625`.

- `Table2_temporal_dx_0p003125.m`  
  Temporal refinement test for Table 2 at fixed `dx = 0.003125`.

- `Table2_extra_dt_0p00625.m`  
  Additional `dt = 0.00625` calculation for the last row of Table 2.

- `Table3_spatial_dt_0p005.m`  
  Spatial refinement test for Table 3 at fixed `dt = 0.005`.

Table 4 is generated by the finite-window test in `reviewer_benchmarks.m`, and its output is written to `reviewer_domain.csv`.

- `plot_ana_long_interaction.m`
- `plot_brother_like.m`

These programs generate the analytical plots used to compare the limiting interaction structures.

## Notes

- All programs are written in MATLAB.
- The parameter values in the scripts are those used in the revised manuscript.
- The scripts are provided to reproduce the reported numerical results; no claim of optimal computational performance is made.
